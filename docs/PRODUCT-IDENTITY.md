# Product Identity

Product cards retain the link hub's existing line-icon, stable `data-project`,
and per-product color conventions. A product's mark is not the site's favicon.

AdBrain uses the exact Lucide Brain geometry generated by the AdBrain repository
at `public/logo.svg`. Its eight paths are embedded locally in the AdBrain card,
with `currentColor` and an `aria-hidden` wrapper because the adjacent label
already names the product. Do not replace it with a generic advertising symbol.

When refreshing the mark, run `npm run generate:icons` in AdBrain and copy the
new geometry without changing other products. In a sibling checkout, run
`node ../adbrain/scripts/check-brand-parity.mjs` to compare all paths. Then run
`npm test`, inspect desktop/mobile rendering, and bump the service-worker cache
when changing the offline shell or its assets.

Production is GitHub Pages from the root of `main`. Check the actual Pages build
commit and the deployed AdBrain SVG; a successful CI job alone is not a deployment.
